# Java Task 3: ATM Interface

## Objective

Create a console-based ATM simulation that lets a customer authenticate and perform basic account operations.

## Planned technologies

- Core Java
- Object-oriented programming (OOP)
- Console input and output

## Planned features

- Authenticate a customer using account details and a PIN.
- Display an ATM menu with available account operations.
- Support balance inquiry, deposit, and withdrawal.
- Check transaction input and prevent withdrawals above the available balance.
- Display a clear result after each operation and allow the customer to exit.
