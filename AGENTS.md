# Oasis Infobyte Java Internship Instructions

This repository contains Java Development Internship tasks for Oasis Infobyte (OIBSIP).

## Repository and task organization

- Keep the GitHub repository named `OIBSIP`. Do not rename it, change its remote, or push changes unless explicitly requested.
- Keep all internship tasks in this repository.
- Name each task directory using `OIBSIP/[TrackName]-[Level/Task]-[ProjectName]/`. For the selected Java tasks, preserve these directory names:
  - `Java-Task-1-Online-Reservation-System/`
  - `Java-Task-3-ATM-Interface/`
- Preserve each task's `README.md`, `src/`, `screenshots/`, and `output/` locations. Store task-specific source and evidence in that task's directory.
- Do not move task files to a separate repository or combine multiple tasks into a single task directory.

## Implementation guidance

- Follow the official Oasis Infobyte task brief and its required behavior. If a brief is missing or ambiguous, document the assumption or ask for clarification before relying on it.
- Explain design and code in beginner-friendly language. Prefer clear names and small, focused methods over clever shortcuts.
- Implement one feature at a time. Keep the README aligned with the current implementation and call out remaining work.
- Do not claim a feature, build, or test is complete unless it has been implemented or run and the result has been verified. State which checks were actually performed.
- Ask before making major architectural changes, changing a task's chosen technology, or restructuring the repository.
- Do not add application code before the user requests implementation work.
