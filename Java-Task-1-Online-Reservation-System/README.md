# Java Task 1: Online Reservation System

## Objective

Create an online reservation application for entering and managing passenger journey reservations through a graphical interface.

## Planned technologies

- Java
- Swing for the desktop user interface
- JDBC for database access
- SQLite for local reservation data

## Planned features

- Provide a login screen for access to the reservation system.
- Collect passenger and journey details to create a reservation.
- Save and retrieve reservation details using JDBC and SQLite.
- Allow a user to look up and cancel an existing reservation.
- Validate required input and show clear success or error messages.
